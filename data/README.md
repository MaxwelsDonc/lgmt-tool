# Data directory — provenance, licenses, and schemas

This directory ships the LGMT evaluation data: source entailment test cases
(from three public datasets), the processed metamorphic-group (MG)
evaluation set used in the paper, and a small demo subset.

## Source datasets and citations

| Dataset | Citation | Original repository |
|---|---|---|
| FOLIO | Simeng Han, Hailey Schoelkopf, Yilun Zhao, et al. "FOLIO: Natural Language Reasoning with First-Order Logic." arXiv:2209.00840, 2022/2024. | https://github.com/yale-nlp/FOLIO |
| LogicNLI | Oren Asel, Hai Kezil, Nachshon Cohen, et al. "LogicNLI: A Dataset for NLI-based Inference in Deductive Logic." 2021. | https://github.com/lgw863/LogicNLI-dataset |
| ProverQA | Hanhao Zhao, Zhengyuan Liu, et al. "ProverQA: An Expert Annotated Dataset for Proof Generation..." 2023. | https://github.com/Zayne-sprague/ProverQA |

(If a citation above is imprecise, please open an issue — corrections are
welcome.)

### Source-case schema (one JSON object per line)

| field | meaning |
|---|---|
| `premises_logic` / `conclusion_logic` | first-order-logic formulas (NLTK syntax) |
| `premises_text` / `conclusion_text` | natural-language rendering |
| `metadata.label` | gold verdict: `True` / `False` / `Uncertain` (legacy; the tool normalizes to `Unknown`) |
| `metadata.data_source` | `FOLIO` / `LogicNLI` / `ProverQA` |
| `metadata.example_id` | id of the originating source-dataset example (for ProverQA also `metadata.original_file`) |

### MG schema (`processed_mgs_3091.jsonl`)

Each line is one metamorphic group:

| field | meaning |
|---|---|
| `source_case` / `followup_case` | source and follow-up `TestCase` objects (same schema as above; a follow-up premise whose text carries a `[Changed_<i>]` tag was rewritten from premise `i`) |
| `mr_name` / `metadata.mr_index` | the metamorphic relation applied, e.g. `MR-E1.4` (see `lgmt/mrs/`) |
| `metadata.data_source` | lower-case source tag (`folio` / `logicnli` / `proverqa`) |
| `metadata.mg_id` | unique group id (`mg_1` … `mg_3091`) |
| `metadata.translation_index` | indices of follow-up premises whose natural language was regenerated by Logic→NL back-translation |

## Statistics

- Evaluation set: **3,091 metamorphic groups** — folio 2,673 / proverqa 325
  / logicnli 93.
- Demo set: **40 groups** (all folio-derived, covering the E/S/P/C MR
  categories), bundled in `lgmt/demo/demo_mgs.jsonl`.
